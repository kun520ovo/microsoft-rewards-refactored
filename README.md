# 🚀 微软积分商城签到（重构版）

## 📋 功能概览

| 功能 | 自动化内容 |
|---|---|
| ✅ 每日签到 | 尝试 App 静默签到和 PC 签到；App 签到需要有效授权 |
| ✅ 新闻阅读 | 查询阅读进度、补充阅读，结束后复查服务器进度 |
| ✅ 活动卡片 | 识别活动并按编号去重，跳过已完成或锁定项目，提交后复查服务器状态 |
| ✅ Quiz／拼图活动 | 将识别到的 Quiz、拼图等项目作为活动卡片尝试处理；Quiz 可单独关闭 |
| ✅ 二次扫描 | 主流程末尾再次扫描活动，处理本轮尚未尝试的新卡片 |
| ✅ PC 搜索 | 使用内置词库或在线热搜词，分批搜索并核验服务器配额 |
| ✅ 连签检测 | 查询必应搜索、每日活动、必应应用和视觉搜索的连续打卡进度 |
| ✅ 每日活动 | 尝试在 Bing 页面就地处理，必要时打开 Dashboard；Rewards 页面也有点击辅助 |
| ✅ 打卡页面辅助 | 在 Rewards 活动页和打卡详情页尝试点击可识别的入口、任务按钮 |
| ✅ 待领取积分 | 检测可领取积分，在 Dashboard 调用领取接口并检查成功标记 |
| ✅ 积分通知 | 浏览器通知，以及企业微信、钉钉、飞书、PushMe、Bark 可选推送 |
| 🛡️ 运行保护 | Bing 登录检查、自动运行地区检查、主任务跨页面互斥和本地跨日中止 |

## 📖 使用方法

1. 安装 ScriptCat 或 Tampermonkey，并导入本脚本。
2. 使用 Microsoft 账号登录 bing.com 和 rewards.bing.com。
3. 打开 Bing 页面，脚本会在后台自动运行，完成签到、阅读、活动、搜索等任务。
4. 首次运行如果提示授权，请点击“手动授权”并完成登录。授权完成后，脚本会自动获取授权信息。
5. 需要立即执行时，打开脚本菜单并点击 🚀 立即运行。
6. 请保持 Bing 账号处于登录状态。退出登录后，重新登录并刷新页面即可恢复运行。

## ⚙️ 配置说明

### 基础配置

| 配置项 | 说明 | 默认值 |
|---|---|---|
| 持续检测 | 全部完成后是否继续运行 | 开启 |
| 锁定国区 | 非大陆 IP 自动停止 | 开启 |
| 搜索间隔 | 每次搜索后随机等待，当前不可在设置中调整 | 5～30 秒 |
| 搜索词来源 | offline 使用内置词库；online 自动轮换热搜接口 | online |
| 授权码链接 | 粘贴登录跳转后的完整 URL | 空 |

### 任务开关

| 任务 | 说明 | 默认 |
|---|---|---|
| 每日签入 | PC+App 签到 | 开启 |
| 新闻阅读 | 阅读文章获取积分 | 开启 |
| 活动卡片 | 领取各类活动奖励 | 开启 |
| Quiz 自动答题 | 处理 Quiz 测验卡片 | 开启 |
| PC 搜索 | 完成搜索任务 | 开启 |

### 通知渠道

支持以下通知渠道（可选配置）：

- **企业微信**：群机器人 Webhook
- **钉钉**：群机器人 Access Token（关键词需包含 `#`）
- **飞书**：群机器人 Webhook（关键词需包含 `#`）
- **PushMe**：`push.i-i.me` 推送 key
- **Bark**：`bark.day.app` 推送 key

## ⚠️ 防封号机制

以下措施用于控制运行频率，不保证账号不会被限制：

1. **随机延迟**：部分任务间及点击前后等待 3-8 秒，具体间隔因操作而异。
2. **搜索间隔**：每次搜索后随机等待 5～30 秒。
3. **随机启动**：自动任务启动前等待 5-60 秒。
4. **IP 检测**：开启锁定国区后，非大陆 IP 自动停止。
5. **搜索限制检测**：连续 3 次检测到未满配额且进度不变时中断搜索。

❓ 常见问题

### Q: 授权码在哪里获取？

A: 脚本会自动打开授权页面，登录后复制地址栏 URL，粘贴到脚本设置的「授权码链接」中。

### Q: 为什么搜索没有积分？

A: 可能是搜索受限，请检查是否开启了「锁定国区」功能，确保使用大陆 IP。

### Q: 如何配置通知？

A: 在脚本管理器中打开脚本设置，找到「通知接口配置」菜单，按提示配置即可。

### Q: 支持哪些浏览器？

A: 支持 Chrome、Edge、Firefox 等主流浏览器，需安装 ScriptCat 或 Tampermonkey 扩展。
